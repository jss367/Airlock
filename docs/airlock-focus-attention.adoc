== Description

// tag::body[]
{manpurpose}.

When xref:guide.adoc#prevent-focus-stealing[focus stealing prevention] keeps a window from taking focus,
Airlock remembers that the window asked and marks its workspace in the menu bar.
`focus-attention` focuses the window that asked last, switching to its workspace if needed.
The request ends when you get there, so running the command again goes to the window that asked before it, on another workspace.

A request also ends when you focus the window's workspace yourself, when the window closes or moves to another workspace, and when Airlock is paused.

If no window is waiting, the command does nothing, prints a message, and exits with non-zero exit code.
// end::body[]
