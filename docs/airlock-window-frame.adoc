== Synopsis
[verse]
// tag::synopsis[]
airlock window-frame [-h|--help] [--window-id <window-id>] (left-half|right-half|center|comfortable)

// end::synopsis[]

== Description

// tag::body[]
{manpurpose}

Positions the focused window (or `--window-id`) within its monitor's usable area, excluding the menu bar and Dock.
The window becomes floating, so automatic tiling preserves the placement.
This command also works with `enable-window-management = false`.

* `left-half` fills the left half of the usable area.
* `right-half` fills the right half of the usable area.
* `center` centers the window without changing its size.
* `comfortable` centers the window at 75% of the usable width and height.

Applying a preset exits Airlock's fullscreen mode and clears its saved restore frame.
Applications may enforce minimum window sizes.
