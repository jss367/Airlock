// =========================================================== Description
== Description

// tag::body[]
Run `/bin/bash -c '<bash-script>'`, and don't wait for the command termination.
Stdout, stderr and exit code are ignored.

For example, you can use this command to launch applications:

[source,toml]
----
option-enter = 'exec-and-forget open -n /System/Applications/Utilities/Terminal.app'
----

Airlock passes the text after `exec-and-forget` directly to Bash, including whitespace and shell quoting.
If you rename a workspace, Airlock preserves this script. Update any workspace references inside the script yourself.

* The command is available in config
* The command is *NOT* available in CLI

// end::body[]
