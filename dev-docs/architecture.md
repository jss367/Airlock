# Airlock architecture

## Project layout

- [`Sources/AppBundle/`](../Sources/AppBundle/): window management, workspace isolation, configuration, and user interface. Exposed as a library by the Swift package.
- [`Sources/AirlockApp/`](../Sources/AirlockApp/): the app entry point, used by the Xcode app bundle and the package-based debug executable.
- [`Sources/Cli/`](../Sources/Cli/): the `airlock` command-line client.
- [`Sources/Common/`](../Sources/Common/): shared argument parsing, client/server protocol, and utilities.
- [`Sources/PrivateApi/`](../Sources/PrivateApi/): the accessibility window-ID bridge.
- [`Sources/AppBundleTests/`](../Sources/AppBundleTests/): Swift tests.
- [`ShellParserGenerated/`](../ShellParserGenerated/): generated shell parser package.
- [`docs/`](../docs/): AsciiDoc command reference, guide, and configuration examples.

[`Package.swift`](../Package.swift) defines the packages and test targets. [`project.yml`](../project.yml) defines the Xcode app bundle project generated by `generate.sh`.

## Client/server interaction

`Airlock.app` is the server. Each invocation of the `airlock` command-line client connects through a Unix-domain socket:

1. The client parses arguments and handles help or parsing errors.
2. It sends the arguments to the app.
3. The app parses the arguments and executes the command.
4. The app returns standard output, standard error, and an exit code.
5. The client prints the response and exits with that code.

## Adding or changing commands

Command implementations live in [`Sources/AppBundle/command/`](../Sources/AppBundle/command/) and argument definitions in [`Sources/Common/cmdArgs/`](../Sources/Common/cmdArgs/).

- Update the command's `docs/airlock-*.adoc` page and include it in `docs/commands.adoc`.
- Consider whether `--window-id` or `--workspace` targeting applies.
- Update [`grammar/commands-bnf-grammar.txt`](../grammar/commands-bnf-grammar.txt) for shell completion.
- Regenerate command help and add relevant tests.
- Render documentation with `./build-docs.sh` and inspect the HTML and manpage output.

## Window management

- [`config/`](../Sources/AppBundle/config/): TOML configuration parsing and hotkey bindings.
- [`tree/`](../Sources/AppBundle/tree/): apps, windows, workspaces, and layout containers.
- [`layout/`](../Sources/AppBundle/layout/): layout calculation and refresh.
- [`focusStealingPrevention.swift`](../Sources/AppBundle/focusStealingPrevention.swift): workspace isolation when another app attempts to take focus.
- [`ui/`](../Sources/AppBundle/ui/): menu bar, switchers, launcher, workspace overview, keyboard visualizer, and overlays.
